# 仓库物资出入库管理系统源码+uniapp小程序

源码地址：ym7k.com/17777/

仓库物资出入库管理系统搭配 Uniapp 小程序端，实现电脑后台管理与移动端操作联动，覆盖物资入库、出库、库存盘点、领用归还、台账查询等全流程，适合小微企业、门店、项目部、学校、社团等各类物资管理场景。整套系统打破传统台账、Excel 表格管理的局限，管理人员不用局限在电脑旁，借助小程序随时随地处理仓库业务，数据实时同步，形成完整的物资管控闭环。<img width="421" height="933" alt="1b7345cc860f45c7877306770c8af3cb" src="https://github.com/user-attachments/assets/4506860e-7b2c-47cc-a319-937fdc286c37" />


系统支持对物资基础档案进行统一维护，管理员可以在后台新增物资分类、录入物资信息，填写物资名称、规格型号、单位、参考单价、存放库区、安全库存等信息。物资支持图片上传存档，方便辨认物料。同时可以维护供应商、领用部门、人员信息，方便后续出入库记录关联对应的主体，让每一笔物资流转都有源可查。物资分类支持多级设置，物料多的时候也能清晰归类，查找更高效。

入库管理模块支持多种入库类型，包含采购入库、调拨入库、退货入库等。新增入库单时选择对应物资、填写入库数量，系统自动记录入库时间、经办人、供应商等信息，提交后库存数量自动增加。每一张入库单据独立编号，方便后续检索追溯，单据信息长期留存，不会丢失。


出库模块主要用于物资领用、调拨出库、报损出库等场景。领用人员可以在小程序端提交领用申请，填写领用物资、数量以及用途，提交后等待管理员审核。审核通过后物资正式出库，库存同步扣减。如果是不需要审批的场景，管理员也可以直接在后台一键出库。系统严格控制库存，当库存不足时会给出提示，避免超领、错领的情况发生。![Uploading 2025070418301716.png…]()



库存盘点是这套系统很实用的功能。仓管人员拿着小程序到仓库现场，直接扫码或者搜索物资核对实物数量，录入实际盘点数量。系统自动对比账面库存和实际库存，生成盘盈、盘亏记录，管理员可填写盘点备注，确认之后自动调整账面库存，解决实物和台账对不上的痛点。同时支持设置安全库存预警，当物资存量低于设定值，后台和小程序都会收到提醒，方便及时采购补货，防止物资断供。

小程序端兼顾一线操作人员使用需求，界面简洁易上手。支持单据提交、扫码查询物资、查看个人领用记录、查看库存数量、查询历史单据。仓管和领用人员不用登录电脑后台，在仓库现场、外勤场景都可以快速完成操作，所有操作记录实时同步到管理后台，两端数据保持一致。

后台拥有强大的单据查询和数据统计能力。可以按照时间、物资、人员、出入库类型筛选所有单据，查看每一条流转记录，做到全程溯源。所有台账支持一键导出表格，用于对账、存档。系统还支持角色权限划分，可以设置仓管员、普通领用人员、管理员等不同身份，不同账号拥有不一样的操作权限，防止越权修改数据，适配团队分工管理。

整套源码可自主部署，数据本地留存，不受第三方平台限制。具备二次拓展空间，可以按需增加采购计划、归还登记、固定资产管理等功能。对比手工记账，这套出入库系统减少错记漏记，提升仓库管理效率，让物资流转清晰可控。<img width="1024" height="509" alt="2025070418301917" src="https://github.com/user-attachments/assets/f87e7176-60c3-4327-a862-fafafcf9e82e" />
